The current collaborator listing contained `joshuapdunlap` as administrator; repository webhook and deploy-key lists were empty. Pages uses Actions, the expected custom domain and enforced HTTPS. These checks do not establish historical account access or audit Google/Cloudflare ownership records.

### Page weight and laboratory limits

The live homepage delivered 133,811 gzip body bytes and decoded to 332,106 bytes. The candidate artifact contains 16,069 HTML bytes plus a separate 4,521-byte rosette asset, reducing raw HTML by about 95%. Local deterministic gzip estimates are 5,271 and 1,592 bytes respectively; these estimates are not new production transfer measurements.

A real 390-pixel browser trace against the loopback QA server recorded a 16,143-byte HTML response body and 16,443-byte navigation transfer size, including the injected QA script references and browser-reported overhead. The rosette appears as one shared resource request. Cache revalidation and warm resources are recorded in the saved trace. This server sends uncompressed HTML; production compression and caching still need a post-deployment check.

The saved mobile-home LCP sample was 204 ms on unthrottled localhost with warm resources. The maximum saved layout-shift value across cases was approximately 0.022. These are instrumented laboratory observations, not field Core Web Vitals. No representative INP measurement is claimed. Shared compressed CSS is 8,137 bytes; initial compressed first-party JavaScript is 667 bytes on home and 1,055 bytes on evidence.
